# Rat AI — контроль кассовых операций

Фронтенд сервиса проверки видеозаписей для кейса ForteBank / Datathon 26. Реализован банковский вариант дизайна: светлый интерфейс с бордовыми акцентами.

Фронтенд подключён к backend: загрузка видео, статус задачи, вердикт и кадры из API. AI-модель подключается отдельно через локальный процесс; без неё анализ завершается ошибкой.

## Backend

API загрузки видео, статусы задач, проверка X-API-Key, SQLite, адаптер локального AI и JPEG-кадры. Запуск, Docker и контракт интеграции: [backend/README.md](backend/README.md). Без настроенной модели API возвращает статус `failed`, а не фиктивный результат.

## Запуск фронтенда

Требуется Node.js 20.19+ в ветке 20 либо 22.12+ (рекомендуется Node.js 24).

```bash
cd frontend
npm ci
npm run dev
```

Откройте адрес, напечатанный Vite (обычно http://127.0.0.1:5173).

```bash
npm run build      # TypeScript и production-сборка
npm test           # проверки валидации, мок-сервиса и отмены запросов
npm run preview    # локальный просмотр production-сборки
```

Структура приложения и контракт интеграции описаны в [frontend/README.md](frontend/README.md).

## Запуск всего сервиса

Создайте `backend/.env` по примеру, настройте ключ и модель, затем из корня: `docker compose up --build`. UI откроется на http://localhost:8080. Для разработки с Vite настройте `frontend/.env` по [инструкции](frontend/README.md).
